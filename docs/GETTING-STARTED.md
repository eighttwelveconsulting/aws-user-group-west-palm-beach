# Getting Started

## What You Need

- Git installed
- GitHub account
- AWS account with MFA enabled
- AWS CLI installed

## First-Time Setup

1. Clone this repository.
2. Create a new branch.
3. Open the lab README and follow it line by line.
4. Commit your notes or fixes to a branch.
5. Open a pull request.

## Local Checks

```bash
pnpm install
pnpm run ci
```
