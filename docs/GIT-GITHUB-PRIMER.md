# Git and GitHub Primer

## Basic Workflow

1. `git checkout -b docs/my-update`
2. Edit files
3. `git add .`
4. `git commit -m "docs: improve getting started steps"`
5. `git push -u origin docs/my-update`
6. Open a pull request

## Pull Request Tips

- Keep PRs small.
- Explain what changed and why.
- Ask for review when checks pass.
