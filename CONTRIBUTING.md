# Contributing

Thanks for helping improve this learning repository.

## New Contributor Flow

1. Create a branch such as `docs/fix-typo`.
2. Make small, focused changes.
3. Run local checks: `pnpm install` then `pnpm run ci`.
4. Open a pull request and complete the checklist.

## Content Standards

- Keep instructions step-by-step.
- Include expected output where possible.
- Include cleanup steps for AWS resources.
- Never commit secrets.
