# Project 01: Serverless API Overview

## Goal

Understand the building blocks of an AWS serverless API architecture before writing infrastructure code.

## Prerequisites

- Complete Lab 01
- Basic understanding of API requests

## Milestones

1. Draw a simple architecture (API Gateway, Lambda, DynamoDB).
2. Describe request flow in plain language.
3. Add a deployment readiness checklist.

## Definition of Done

- [ ] Architecture diagram or bullet flow included
- [ ] Request/response path documented
- [ ] Risks and cost considerations listed

## Stretch Task

Document how you would monitor latency and errors.
